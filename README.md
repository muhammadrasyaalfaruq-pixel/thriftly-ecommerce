# Thriftly - Online Thrift Store

Tugas Akhir Semester 3 - Mata Kuliah E-Commerce
Web jual-beli baju thrift/preloved (marketplace sederhana).

## Teknologi
HTML, CSS, JavaScript, Node.js (Express), MySQL

## Anggota Kelompok
| Nama | Modul | Branch |
|---|---|---|
| Rasya | Fondasi, Login/Daftar, Admin master | feature/database-rasya |
| Adit | Katalog dan Nego | feature/adit |
| Apip | Penjual dan Produk | feature/apip |
| Dandi | Keranjang dan Checkout | feature/dandi |
| Fandi | Pesanan, Pembayaran, Review | feature/Fandi |

## Struktur Folder
- backend/ : server dan API (Node.js + Express)
- frontend/ : tampilan (HTML, CSS, JS)
- database/ : file SQL
- docs/ : dokumentasi dan ERD
